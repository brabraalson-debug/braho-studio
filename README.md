# Braho Studio

A responsive, dependency-free portfolio inspired by the Atlas Design Agency & Marketing Portfolio viewed in the owner's Framer project. Built with HTML, CSS and JavaScript; no Framer subscription or build step required.

## Preview

Run `python3 -m http.server 4173` from this directory and open http://localhost:4173.

## Personalize

- Replace the four concept previews in `index.html` with your real project images and titles.
- Update the project descriptions in `script.js`.
- Set `contactEmail` in `script.js` to your public business email.
- Adjust studio copy, services and social links as needed.
- Typography uses Golos Text via Google Fonts, with Arial as fallback. All preview artwork is CSS, so there are no external image dependencies.

## GitHub Pages

This folder is ready for static hosting. In repository Settings → Pages, choose a supported publishing source and publish the root directory. Hosting has not been enabled. Private repository Pages availability depends on your GitHub plan; do not change visibility just to deploy without considering whether you want the source public.
