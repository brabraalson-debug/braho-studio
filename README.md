# Braho Studio

Static graphic design portfolio built with HTML, CSS and JavaScript.

## Preview

Run `python3 -m http.server 8765` in this folder and open http://localhost:8765.

## Contents

- AURA, AVEN and SXC identity concept presentations
- NEURO//DIVINITY cover art and packaging
- The Last Prophecy poster series
- Artwork-matched galleries, silver animated hero, scrolling logos and text reveals
- Responsive dark layout and reduced-motion support

Assets are stored in `assets/`. No build step is needed.

## Before publishing

Set `contactEmail` in `script.js` to the public studio email. Confirm studio copy, concept labels and social links. SXC application studies use the alternate wordmark from the source identity review; its signature uses the corrected outlined logo.

Saving this repository does not enable GitHub Pages or change repository visibility.
